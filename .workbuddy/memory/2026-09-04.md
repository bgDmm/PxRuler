## 像素尺刻度样式调整（ruler.js）

用户截图反馈：刻度上覆盖了一条半透明横线，影响观感；希望刻度只保留"刻度 + 数字"，数字加描边以便任意背景色下都能看清。

**根因**：`drawHorizontalTicks` / `drawVerticalTicks` 中对每一个像素都绘制了一条 0.5px 宽、4px 高的细线（`COLORS.tickPixel = #718096`）。这些密集细线在高分屏缩放后糊成一条半透明灰带，覆盖在刻度上。

**改动**（commit `9e57aeb`）：
1. 两个绘制函数的刻度分支末段由「画 4px 每像素细线」改为 `continue`，即跳过非 5 的倍数像素。现仅保留 5 / 10 / 50 / 100 刻度 + 百位数字。
2. 四处文字渲染（横向/纵向的百位标签、hover 数值）均改为先 `strokeText` 后 `fillText`：
   `lineWidth = 3`、`lineJoin = 'round'`、`strokeStyle = 'rgba(0, 0, 0, 0.7)'`，填充色保持 `#ffffff`。
3. `COLORS.tickPixel` 已无引用，但保留在配色表中备用。

**待办 / 提醒用户**：刻度线本身仍是固定的浅色（`#ffffff` / `#cbd5e0` 等）。若用户把背景改成浅色，刻度线会看不清——只有数字因描边仍可读。如需完整适配，应给刻度线也加描边或按背景亮度自适应。
